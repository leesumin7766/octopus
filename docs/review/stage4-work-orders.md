## R1 반복을 말로 입력 + 낱말 하나짜리 요일 정리 + Mac 키 안내

- **파일:** `src/shared/tasks/quickParse.ts`(+ 미리보기 칩은 기존 `formatRepeat`), `src/renderer/ui/MultilineInput.tsx`·`ko.ts`(키 안내)
- **할 일:**
  1. 반복 표현 더 알아듣기: "격주 월"(2주마다 월), "N주마다 월 수"·"N주마다 평일", "N일마다", "N개월마다"(그 날짜 기준). 기준일(anchor)은 지금 규칙대로 그 할 일 날짜. 미리보기 칩에 그대로 보이게.
  2. 한 글자 요일 '일' 혼자는 날짜로 읽지 않는다("청소 일" → 제목 그대로). '일요일'·'다음주 일'·'이번주 일'·'매주 일'·'격주 일' 은 계속 일요일. 다른 한 글자 요일(월~토)은 지금처럼.
  3. 여러 줄 입력 키 안내: Mac 이면 "⌘+Enter 저장", 아니면 "Ctrl+Enter 저장"(플랫폼은 preload 가 이미 주는 값이 있으면 그것, 없으면 `navigator.platform`).
- **끝 기준:** 위 표현들이 맞는 RepeatRule·첫 날짜로 해석되고, 체크(완료) 뒤 다음 회차가 주기대로 생긴다(저장소 시험). 기존 quickParse 시험 전부 통과. "청소 일" → 날짜 없음.

## F6 할 일 탭 검색

- **파일:** `src/renderer/tasks/TasksScreen.tsx`(+ 필요하면 새 `TaskSearch` 부품), `ko.ts`
- **할 일:** 할 일 탭 위쪽에 제목·설명 검색칸(접근성 이름 있음). 글을 쓰면(짧게 기다렸다가) 모든 보기(수신함·오늘·예정·나중에·완료·안 하기로 함)에서 찾은 할 일을 보기별로 묶어 보여 준다. 대소문자·앞뒤 공백 무시, 찾은 부분 강조(메모 화면 `highlightMatches` 재사용). 결과 행을 누르면 그 보기로 가서 선택(F3 의 openTask 방식). Esc 나 지우기 버튼으로 검색 끝 → 원래 보기. 결과 없으면 짧은 안내.
- 새 IPC 를 만들지 않는다: 화면이 이미 읽는 목록들(보기별 목록 + `listCanceled`)에서 거른다. 필요한 목록을 아직 안 읽으면 검색을 시작할 때 읽는다.
- **끝 기준:** "보고" → 여러 보기의 '보고서'가 보기 이름과 함께 나옴, 누르면 그 할 일 선택. 설명에만 있는 낱말도 찾음. 완료·안 하기로 함도 찾음. Esc → 검색 전 보기 그대로.

## C2 달력 탭 Google 일정 상태

- **파일:** `src/renderer/calendar/CalendarScreen.tsx`, `src/renderer/home/calendar/DayDialog.tsx`(Google 부분 표시), 홈 달력 카드의 주기 읽기 코드 참고
- **지금:** 달력 탭은 Google 일정을 못 읽으면 조용히 빈칸이고(null), 다시 읽지 않는다. 원본 열기 실패도 조용하다.
- **할 일:** 불러오는 중 / 연결 안 됨 / 실패([다시 시도]) / 일정 없음 을 구분해 보인다(홈 카드와 같은 문구 재사용). 홈과 같은 주기로 다시 읽고, 창이 다시 포커스를 받을 때와 자정이 지나면 다시 읽는다(늦게 온 응답이 새 응답을 덮지 않게). 원본 열기가 실패하면 짧게 알린다.
- **끝 기준:** 가짜 응답으로 네 상태가 각각 보이고, 실패 → [다시 시도] → 성공. 순서가 뒤바뀐 응답 시험. 자정 시험(가짜 시계).

## C3 미래 반복을 '예정(반복)'으로 보이기

- **파일:** `src/renderer/calendar/CalendarScreen.tsx`, `src/renderer/home/cards/CalendarCard.tsx`(달 칸 표시), `DayDialog.tsx`(그날 목록), 공용 계산은 `src/shared/tasks/repeat.ts` 의 다음 회차 함수 재사용(새 순수 함수 하나 가능)
- **지금:** 반복 할 일은 저장된 회차(가장 가까운 하나)만 보인다. 그 뒤의 날은 비어 보여 "할 일 없는 날"로 오해할 수 있다.
- **할 일:** 보이는 달 범위 안의 미래 회차를 계산해(저장하지 않음) 달 칸에는 흐린 점·수, 날짜 상세에는 흐린 줄 "예정(반복)"으로 보인다. 체크·편집은 안 되고, 누르면 실제 회차(저장된 할 일)의 상세로. 체크리스트 항목(요일 루틴)도 같은 방식으로 미래 날짜에 흐리게. 끝나는 날이 있는 규칙은 그 뒤 안 보임.
- **끝 기준:** 매주 월 반복 → 이번 달 남은 월요일들에 흐린 표시, DB 행 수는 그대로(시험으로 확인). 실제 회차를 완료하면 다음 회차가 실제가 되고 흐린 표시와 겹치지 않음.
