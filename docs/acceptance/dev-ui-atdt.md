## 1. 알림 표시 (제목 줄 왼쪽)

ATDT 의 `NoticeBell` 과 같은 자리·모양: 알림이 있을 때만 작은 호박색 `🔔 알림 1` 이 보인다. 없으면 아무것도 없다.

| | ATDT | Octopus |
|---|---|---|
| 표시 | 확인 안 한 알림 수 | 같음 |
| 누르면 | 기록 탭으로 이동 | **바로 아래에 작은 목록이 열리고 그 안에서 처리** (요청 1) |
| 업데이트 | 오른쪽 아래 떠 있는 대화상자 | 목록 안 한 항목: `새 버전 0.2.0` + 바뀐 점 4줄 + [나중에] [받기] → 진행 막대 → [나중에] [다시 시작해서 설치] |

- [나중에]는 지금 단계의 알림만 치운다. 다음 단계(받기 완료)가 되면 다시 나타난다.
- Esc·바깥 누르기로 목록을 닫는다. 확인 중·실패는 종을 울리지 않는다(설정 > 업데이트 에만).
- 지금 알림은 업데이트 하나뿐이다. 다른 알림(예: Arm 연결 끊김)을 같은 목록에 더할 수 있게 목록 구조로 만들었다.
- 파일: `src/renderer/notices/NoticeBell.tsx` (1차의 `update/UpdateChip.tsx` 는 삭제)
- 증거: `evidence/ui-update/notice-bell-update.png`

## 3. 달력 탭 (왼쪽 메뉴 '할 일' 바로 아래 '달력')

ATDT 달력 탭과 같은 구성:

- 왼쪽: 큰 월간 달력. `‹ 2026년 11월 › 오늘` · 오른쪽 위 `이 달 완료 2/11`. 칸마다 날짜(오늘은 채운 원)와 할 일 표시 **● 다 함 / ◐ 일부 / ○ 못 함** + 개수. 일요일 빨강·토요일 파랑 머리글.
- 오른쪽: 고른 날짜의 할 일. 홈의 날짜 상세와 **같은 부품**(`DayDialog` 의 `variant="panel"`)이라 추가·완료·편집이 그대로 된다. ‹ › 로 날짜를 옮기면 달력도 그 달로 따라간다.
- 작성 중에 다른 칸을 누르면 먼저 묻는다(버리기 / 계속 쓰기).
- 데이터가 바뀌어도 화면을 다시 그리지 않는다(홈처럼 스스로 다시 읽음) — 고른 날짜와 쓰던 글이 남는다.
- 창 너비 768px 이상이면 나란히, 그보다 좁으면 위아래.
- ATDT 에 있는 메모·일일노트·활동 기록 칸은 Octopus 에 해당 데이터가 없어 넣지 않았다. 칸 아래 범례 줄도 글자를 줄이려고 뺐다(칸에 마우스를 올리면 "할 일 3개, 완료 1개").
- 파일: `src/renderer/calendar/CalendarScreen.tsx`
- 증거: `evidence/ui-update/calendar-screen-900x700.png`

## 4. 글자 줄이기 · 사용성 (요청 3·5)

ATDT 에서 가져온 원칙: **설명문 대신 짧은 placeholder·툴팁, 행 동작은 마우스를 올리거나 키보드로 들어갔을 때만, 쓸 수 없는 버튼은 숨김.**

| 화면 | 이전 | 이후 |
|---|---|---|
| 홈 달력 카드 | `‹ 2026년 11월 [오늘] ›`, 아래에 "Google 캘린더 연결은 아직 준비 중이에요." / "연결하지 않았어요 [연결]" | `‹ 2026년 11월 ›` (선 아이콘). Google 줄은 연결됐을 때(오늘 일정 n개)나 끊겼을 때([다시 연결])만 |
| 날짜 상세(홈 대화상자·달력 패널) | `[이전 날] [오늘] [다음 날] [닫기]`, "저장 날짜: …" 줄, "저장하는 중이에요…/추가했어요." 줄, '시간 지정/시간 미지정' 제목, 완료 항목의 '완료' 표, 항목마다 [편집] 버튼, 연결 안 된 Google 안내·[연결], 다른 날의 "오늘 날짜에서 확인할 수 있어요" | `‹ 날짜 › ×`. 저장 날짜·저장 중 문구·묶음 제목·'완료' 표 없음(줄긋기로 충분). **제목을 누르면 편집**. '지난 미완료' → '지난'. Google 은 오늘 + 연결됨/끊김일 때만 |
| 할 일 화면 입력 | "할 일을 입력하고 Enter 를 누르세요. 예: …" + 늘 보이는 '알아들은 것' 설명 줄 | "할 일 추가 · 예: 내일 3시 보고서 #업무 !높음". 알아들은 것 줄은 입력을 시작했을 때만(홈과 같게) |
| 지난 할 일 행 | 항목마다 [오늘로][나중에][날짜…] 늘 보임 | 마우스를 올리거나 키보드로 들어갔을 때만(날짜 칸을 연 동안은 계속) |
| 메모 화면 | "메모를 적고 Ctrl+Enter 로 저장하세요. 여러 줄도 괜찮아요." + 버튼 옆 "Ctrl+Enter 로 저장" + 항목마다 [고정][할 일로 만들기][삭제] 늘 보임 | "메모 (Ctrl+Enter 로 저장)" 하나(버튼 툴팁에도). 항목 동작은 hover/focus 때만 |
| 홈 메모 카드 | "한 줄 메모 (Enter)", 빈 상태 "메모가 없어요. 아래에 한 줄로 적어 보세요." | "메모 추가", "메모가 없어요." |
| Arms 화면 | 제목 아래 소개 문장, 카드마다 능력 칩(일정 읽기·원본 링크…), "로그인 한 번으로 연결"/"폴더를 골라 연결" 각주, 긴 MCP 설명 | 소개·능력 칩·각주 없음. MCP 설명 한 문장 |
| 설정 > 업데이트 | 아래 안내 문장 | 없음 |

## 6. 남은 일

- 진짜 업데이트(릴리스 받기·설치)는 아직 검증하지 않았다(1차 문서 §4 와 같음). 나중에 소스 저장소를 비공개로 바꾸고 배포 전용 저장소를 따로 둘 계획이므로, 그때 `electron-builder.yml` 의 `publish.repo` 를 바꿔야 한다.
