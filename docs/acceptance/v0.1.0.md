## 4. 개선 사항

### 4.1 사용자 관점

**높음**
1. **원형 메뉴 기본 8칸 중 3칸이 쓸 수 없는 상태로 고정.** 메일·위키는 v0.1에 없는 기능이고, 캘린더는 Google 설정이 있어야 켜집니다. 새 사용자가 처음 여는 메뉴의 절반 가까이가 흐립니다. 기본값을 지금 쓸 수 있는 동작(할 일 보기·체크리스트·메모 보기·설정)으로 채우고, 없는 기능은 목록에서 빼는 편이 낫습니다.
2. **지시하기 응답을 한 번에 받음(스트리밍 없음).** 긴 답이면 "생각 중…"만 오래 보입니다.
3. **지난 할 일 행에 체크박스 두 개(선택용·완료용).** 무엇을 누르는지 헷갈립니다. 선택은 행 클릭이나 다른 모양으로 바꾸는 것을 권합니다.
4. **"이 빌드에는 Google 연결이 아직 설정되지 않았어요".** "빌드"는 개발자 말입니다. 일반 사용자 문구로 바꾸는 것을 권합니다.
5. **서명 없는 설치 파일.** 처음 실행할 때 Windows SmartScreen 경고가 뜹니다.

**보통**
6. 할 일·체크리스트·메모 화면은 색만 목업을 따르고, 배치는 목업(Tasks.dc.html)과 다릅니다. 목록 체크박스와 날짜 입력("연도-월-일")은 브라우저 기본 모양입니다.
7. 예정 보기에 날짜별 묶음이 없고, 완료 보기에 완료 시각이 없습니다. 취소(canceled)로 바꾸는 화면과 반복 규칙을 고치는 화면도 없습니다(빠른 입력으로만 만듦).
8. 날짜 표기가 화면마다 다릅니다(후보 "마감 2026-11-27", 목록 "11/24").
9. 루틴 기록에서 "앱을 안 켠 날"과 "못 한 날"이 구분되지 않습니다. 루틴 순서를 바꿀 수 없습니다.
10. 메모는 마크다운으로 렌더링하지 않고(글자 그대로 표시, 보안상 의도), 검색어 강조가 없습니다.
11. 창 폭 760px 이하에서 홈 카드를 세로로 쌓지 않습니다. 오늘 할 일 카드가 작으면 "전체 보기"가 스크롤 아래로 숨습니다.
12. 옵시디언 "적어 넣기"는 저장 후 3초가 지나면 읽어 갑니다. 한 줄을 쓰다 3초 넘게 멈추면 쓰던 줄을 가져갈 수 있습니다.
13. 아이콘이 임시입니다.

### 4.2 개발자 관점

**높음**
1. **`npm run dev`가 main 코드 변경 때 앱을 다시 시작하지 않음.** 화면만 새로 바뀌어 main과 renderer가 어긋납니다(이번 인수 테스트에서 실제로 오류가 남). `electron-vite dev --watch`로 바꾸면 main도 다시 시작됩니다.
2. **README가 비어 있음**(`# octopus` 한 줄). 개발 환경 준비, 대문자 `C:` 경로에서 테스트하기, `ELECTRON_RUN_AS_NODE` 주의, 캡처 사용법, 설치 파일 만드는 법을 적어야 합니다.
3. **IPC 핸들러가 보낸 쪽 프레임을 검사하지 않음**(Electron 보안 권장 사항 17번). 창이 하나라 위험은 낮지만, 공통 래퍼에서 `event.senderFrame`의 출처를 확인하면 좋습니다.

**보통**
4. `safeStorage.isEncryptionAvailable`가 지원 중단 예정입니다(`isAsyncEncryptionAvailable`로 교체).
5. 릴리스가 없을 때 업데이트 확인이 stderr에 스택 전체를 남깁니다. 한 줄 로그로 줄이는 것을 권합니다.
6. GitHub Actions의 `checkout`/`setup-node` v4가 Node 20 지원 중단 경고를 냅니다(v5로 올리기).
7. 개발 의존성에 중간 등급 취약점 6건이 있습니다(minimatch, electron-builder 경유). 설치 파일에는 들어가지 않습니다.
8. 캡처용 코드가 번들에 들어 있습니다(패키지 앱에서는 비활성). 빌드 설정으로 빼면 더 깔끔합니다.
9. 반복 규칙 한계: "매년 2/29"는 평년을 지나면 2/28로 고정되고(계약 확장 필요), 격주 같은 주기는 마지막 날짜를 기준으로 셉니다.
10. 이 PC 환경 문제: 소문자 `c:` 경로나 Git Bash에서는 vitest가 실패하고, 127.0.0.1 listen이 가끔 EFAULT로 실패합니다(코드에 재시도로 대비함). 원인은 확인하지 못했습니다.
