## C1 보완 사항

1. **선택 날짜를 명확히 표시한다.** 월 카드에서 오늘과 선택 날짜를 별도로 표시하고, 상세 닫은 후에도 선택을 확인할 수 있게 한다. 상세 안에서 날짜를 옮겼을 때 선택 의미도 일치해야 한다. 열기 전 보던 월·닫기 후 포커스 복귀 규칙은 유지한다.
2. **새 기본 메뉴의 캘린더를 로컬 달력으로 연결한다.** 기존 저장된 사용자 8칸은 유지한다. 이는 사용자에게 다시 결정을 요구할 사항이 아니라 Google 없이 기본 달력을 쓰겠다는 방향의 구현이다. 기존 Google 웹 열기 액션은 별도 선택으로 유지한다.
3. **날짜 상세가 열린 동안 Ctrl+K로 모달이 중첩되지 않게 한다.** App의 전역 캡처 키 핸들러를 포함해 확인한다. 날짜 상세를 유지하고 전역 명령 단축키를 무시하는 단순 동작을 기준으로 테스트한다. 기존 정상 화면에서 Ctrl+K는 작동해야 한다.
4. **긴 할 일 제목을 확대 화면에서 읽을 수 있게 한다.** 현재 TaskList의 `truncate`만으로는 잘린 제목을 확인할 방법이 없다. 상세에서는 줄바꿈을 허용하고 긴 문자열도 영역을 넘지 않게 한다.
5. 달력 재조회 시 로딩·오류·빈 결과를 구분한다. 기존 외부 창에서 돌아왔을 때, 오늘이 바뀌었을 때 날짜별 개수가 갱신되는지도 확인한다.

`tests/renderer/c1Review.test.tsx`는 요구를 검증하는 독립 테스트다. 테스트를 삭제하거나 기대를 낮추지 말고 기능을 보완한다. 실패 재현 결과와 수정 후 통과 결과를 보고한다.

- 읽기 전용 날짜 범위 조회와 IPC 추가는 기존 코어/Arm 경계를 지키는 가산적 변경으로 수용한다. 별도 DB 테이블은 필요 없다.

- App 전체 key 재마운트에 의한 입력 유실은 C2에서 반드시 해결한다. 갱신 때문에 사용자가 보고 있는 월·상세가 초기화되지 않게 해야 한다.
- C1 보완 후 Codex가 다시 검증한다. C2/S1은 별도 전달 시 시작한다.
